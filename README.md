# Claude alone on an island for 30 days

A simulated island, no task, 30 days, Claude Opus 5.5 via `claude -p` with tools disabled.
Rules are in the docstring of `game.py`; `island.jsonl` is the full log (every prompt and reply).

Run your own: `python game.py out [model]` (needs the Claude Code CLI). Replay a log: `python replay.py out/island.jsonl`.

Page: https://denzil10.github.io/claude-alone-island/
